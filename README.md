# JPYCスパチャ

**配信者ならだれでも使える、JPYCの投げ銭チャット欄サービス**です。
YouTubeライブのチャット欄のように、JPYCの投げ銭だけが流れます。

**サービスのURL： https://sazinoki-2.github.io/JPYCspchat/**

- 配信者：サービスのURLを開く → 右上の黄色い「配信者」ボタン → その場に出るウィンドウでウォレット接続・配信者名 →「この画面を自分のチャット欄にする」→ 画面はそのまま、URLだけが自分専用になる（登録なし・無料）
- 視聴者：そのURLでコメントを書いて「JPYC」→ 金額をえらぶ → ウォレットで承認
- 配信者は同じURLを小窓かOBSのブラウザソースで開いておくだけ。届いたら演出と音つきで流れる

画面はチャット欄の1枚だけで、切りかわりません。URLは配信者ごとに1本。配信者も視聴者も、スマホもPCも、同じ画面です。
ウォレット接続は右上（YouTubeのログインと同じ場所）。入力欄には、YouTubeのコメント欄のように自分のアイコンと名前が出ます。

## しくみ

```
サービスのURL ── 右上で接続・名前 ──▶ https://<サービス>/#to=<受け取りアドレス>&name=<配信者名>
                                              │  (# の後ろはサーバーに送られない。どこにも保存しない)
                                              ▼
視聴者のウォレット ──(JPYC を直接送る / Polygon)──▶ 配信者のウォレット
        │                                              ▲
        │ 送金番号・なまえ・コメント だけ                  │ ページが数秒おきにチェーンを見に行く
        ▼                                              │
     Firebase ─────────(送金番号で1件ずつ読む)──────────▶ チャット欄に表示
```

- お金はこのサービスを通りません（預からない）。配信者はガス代を払いません。
- 送る人は、承認のときにガス代（POL）が少しかかります（Polygonなので1回0.1〜2円くらい）。
  POLがない人は、HashPort Walletから受け取りアドレスに直接送れます（コメントなしで流れます）。
- 100 JPYC未満の送金は表示しません（いたずら・ゴミ送金よけ。`config.js` の `minTip`）。
- 送る画面には、いつも「受け取り先の名前とアドレス」を出しています（なりすまし対策）。

## Firebaseに送るデータ（最小限）

| 項目 | 送る？ | |
|---|---|---|
| 送金番号（tx hash） | 送る | 文書の名前として使う。もともとチェーンで公開されている番号 |
| なまえ | 送る | 16字まで |
| コメント | 送る | 金額に応じて50/100/200字まで |
| 金額・アドレス・日時 | 送らない | チェーンから読む |
| 配信者の名前・受け取りアドレス | 送らない | URLの `#` の後ろにだけある |
| ログイン情報・端末情報・アクセス解析 | 送らない | ログインなし。アナリティクスも使わない |

`firestore.rules` で「なまえ・コメントの2つ以外は保存できない」「書き換え・削除できない」「まとめて読めない」を強制しています。

## 運営者がやること（はじめに1回だけ）

ページは **GitHub Pages** で公開しています。`main` に push すると、GitHub Actions（`.github/workflows/deploy.yml`）が自動でビルドして公開します。
サービス全体の設定は `public/config.js` の1か所だけです（配信者ごとの設定はありません）。

> いまの状態（2026-09-29）：0（GitHub Pages）と 1（Firebase：プロジェクト `jpycspchat`）は設定ずみ。**のこりは 2 の Reown だけ**です。

### 0. GitHub Pages（最初の1回だけ）
リポジトリの **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** にする。
以後は push するたびに自動で公開されます（Actions のタブで進み具合が見られます）。

### 1. Firebase（コメント置き場。ページの公開には使わない）
1. https://console.firebase.google.com で「プロジェクトを作成」（Googleアナリティクスは「有効にしない」でOK）
2. 左メニュー「Firestore Database」→「データベースを作成」→ 本番環境モード、場所は `asia-northeast1`（東京）
3. 「ルール」のタブを開き、このリポジトリの `firestore.rules` の中身をまるごと貼って「公開」
   （コマンドでやるなら `npx firebase-tools login` のあと `npm run deploy:rules -- --project <プロジェクトID>`）
4. 歯車「プロジェクトの設定」の **プロジェクトID** を `public/config.js` の `firebase.projectId` に書く
   （使うのは Firestore だけなので、`apiKey` などは要りません。いまは `jpycspchat` が入っています）

最初は無料プラン（Spark）で足ります。使う配信者が増えて読み込みが1日5万回を超えるようになったら、従量課金プラン（Blaze）に切りかえます。

### 2. WalletConnect（Reown）
1. https://dashboard.reown.com に無料登録 → プロジェクトを作成
2. 表示された Project ID を `public/config.js` の `reownProjectId` に貼る
3. プロジェクトの「Domain」（許可するドメイン）に `https://sazinoki-2.github.io` を追加

- Project ID が**まだ無いあいだ**も本番で動きます。そのあいだの払い方は「ブラウザに入っているウォレット」だけです
  （PCの MetaMask 拡張機能、MetaMask などのウォレットアプリの中のブラウザ）。
  ふつうのスマホのブラウザで開いた人は「POLがない人はこちら」からアドレスに直接送れます（コメントなし）。
- Project ID を入れると、スマホの HashPort Wallet・MetaMask アプリにも WalletConnect でつながるようになります。
- Firebase の `projectId` が空のあいだは、チャット欄は「DEMO」表示で動きます（送る画面は見本で、実際には送りません）。

### 3. 公開
`public/config.js` を書きかえて `main` に push するだけです。数分で https://sazinoki-2.github.io/JPYCspchat/ に反映されます。
パソコンに何も入れなくても、GitHub の画面で `public/config.js` を開き、鉛筆マーク（Edit）で書きかえて「Commit changes」を押せば同じです。

### 秘密の情報について
- このリポジトリに、秘密鍵・シードフレーズ（シークレットフレーズ）・パスワードは**一切入っていません**。今後も入れないでください。
- このサービスが秘密鍵やシードフレーズを聞くことはありません。送金の承認は、いつも各自のウォレットアプリの中で行います。
- `public/config.js` に入れる値（FirebaseのプロジェクトID・ReownのProject ID）は、公開されたページに必ず載る「表札」のようなもので、秘密ではありません。

### コメントを消したいとき（運営者）
Firebaseコンソール →「Firestore Database」→ `tips` → 該当する送金番号の文書を削除。
投げ銭（金額）はチェーンの記録なので残り、コメントなしの表示になります。

## 配信者の使いかた

1. サービスのURLを開き、右上の黄色い「配信者」ボタン → ウォレット接続・配信者名 →「この画面を自分のチャット欄にする」
2. 出てきたURLを**配信の概要欄**に貼る（QRは「QRを画像で保存」→ OBSの画像ソースに。あとからも右上の「配信者」ボタンでいつでも出せます）
3. 同じURLを**OBSのブラウザソース**に入れる（幅460・高さ800くらい。まわりは自動で透明になります）
   - 音を配信に乗せるなら「OBSで音声を制御する」にチェック
   - 小窓で開いてウィンドウキャプチャでもOK（最小化はしない。ページを1回クリックすると音が出ます）
4. `Shift` + `T` で、自分の画面にだけテスト投げ銭が流れます（100 → 500 → 300 → 1,000 → 10,000 の順）

## 開発
- `npm install` → `npm run dev` で手元確認（http://localhost:5173）。チャット欄は `http://localhost:5173/#to=<アドレス>&name=<名前>`
- `npm run build` で `dist/` にできるものが、そのまま GitHub Pages に載ります（`vite.config.js` で相対パスにしているので、サブフォルダでも動きます）
- 開発中だけ：URLに `?slow=5` でオープニングをゆっくり再生、ブラウザのコンソールで `__testTip(10000)` のように金額指定のテスト
